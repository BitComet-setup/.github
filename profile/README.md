## 🧠 Overview

BitComet is a cross-protocol BitTorrent, HTTP and FTP client written in C++ for Microsoft Windows and available in 52 different languages. Its first public release was version 0.28.

Published by BitComet Development Group (China). Category: BitTorrent client. Licence: Adware.

The archive in this repository contains the Windows utility itself plus the runtime components required for the first launch.
